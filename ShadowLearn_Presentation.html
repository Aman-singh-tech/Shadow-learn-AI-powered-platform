🔧 Backend AI Engine (aiController.js)
  • Uses @google/generative-ai official Node.js SDK
  • Initializes: new GoogleGenerativeAI(API_KEY)
  • Model: gemini-3-flash-preview (high-speed, low-latency)
  • Accepts any user prompt via POST body
  • Returns structured JSON: { success, result }
  • Full error handling with status codes
⚛️ Frontend AI Interface (AISearch.jsx)
  • Real-time prompt input with submit handler
  • Axios POST request to /api/ai/generate
  • Streams and renders Markdown response
  • Uses react-markdown for rich text display
  • Loading state with animated spinner
  • Toast notifications via react-hot-toast
🎯 AI Use Cases in ShadowLearn
  • Natural language search across all company knowledge
  • Answering "How do I fix X?" with documented solutions
  • Generating learning module content suggestions
  • Intelligent handoff checklist recommendations
  • Workflow summary and description generation
  • Insight analysis and productivity reports
🛡️ API Security & Configuration
  • API key stored in .env (never exposed to client)
  • Protected via Express middleware authentication
  • Rate-limited to prevent abuse
  • CORS configured for specific frontend origin only
  • JWT-based user authentication before AI access
  • Environment-based config in config/config.js

Backend Architecture
RESTful API Structure
ShadowLearn exposes a clean, well-organized REST API with 9 distinct route groups covering all major functional domains.
🔐 /api/auth — Authentication
POST/register — User signup
POST/login — Email/password login
POST/google — Google OAuth 2.0 login
GET/me — Get current user (protected)
🤖 /api/ai — AI Engine
POST/generate — Gemini AI content generation
📹 /api/workflows — Workflow Management
GET/ — Get all workflows
POST/ — Create new workflow
PUT/:id — Update workflow
DEL/:id — Delete workflow
💡 /api/solutions — Solution Logs
GET/ — Get all solution logs
POST/ — Log a new solution
PUT/:id — Edit solution
DEL/:id — Remove solution
📚 /api/modules — Learning Modules
GET/ — Get all modules
POST/ — Create module
PUT/:id — Update module
DEL/:id — Delete module
🔄 /api/handoffs — Handoff System
GET/ — List all handoffs
POST/ — Create handoff
PUT/:id — Update handoff
📊 /api/dashboard — Analytics
GET/stats — Summary statistics
GET/recent — Recent activity
💡 /api/insights + /api/users
GET/insights — Organizational insights
GET/users — All user profiles
PUT/users/:id — Update expert profile
